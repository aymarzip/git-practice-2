# Навчальний проєкт — Практична робота №2

Репозиторій для виконання практичної роботи №2 з дисципліни «Програмне забезпечення ПК».

## Тема
Робота з гілками та вирішення конфліктів злиття у Git.

## Що зроблено в роботі
1. Створено гілку `feature-contacts` для додавання секції контактів у `index.html`.
2. Виконано злиття гілки `feature-contacts` у `main` (fast-forward злиття).
3. Створено дві паралельні гілки: `variant-a` та `variant-b`.
4. В обох гілках змінено заголовок сторінки для створення штучного конфлікту.
5. Виконано злиття `variant-b` у `main`, вручну вирішено конфлікт рядків у `index.html` і створено merge-коміт.

## Структура репозиторію
- `index.html` — сторінка проєкту
- `css/style.css` — таблиця стилів
- `assets/preview.png` — знімок сторінки
- `LICENSE` — файл ліцензії MIT

## Гілки проєкту
- `main` — основна гілка з фінальним кодом після вирішення конфлікту
- `feature-contacts` — гілка з початковим додаванням контактів
- `variant-a` — гілка з першим варіантом заголовка
- `variant-b` — гілка з другим варіантом заголовка

## Як запустити
Склонувати репозиторій та відкрити `index.html` у браузері:
```bash
git clone https://github.com/aymarzip/git-practice-2.git
```
