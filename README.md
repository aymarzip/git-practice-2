# Навчальний проєкт — Практична робота №2

**Тема:** Гілки, вирішення конфлікту злиття  
**Дисципліна:** Програмне забезпечення ПК  
**Автор:** Aymar (`aymarzip`)  

## Мета роботи
- Освоєння роботи з гілками у системі контролю версій Git.
- Створення тематичних гілок задач та фіксація змін.
- Виконання злиття (Fast-Forward merge) гілки в основну `main`.
- Моделювання конфлікту злиття при паралельній зміні одного рядка двома гілками.
- Вирішення конфлікту злиття, усунення маркерів конфлікту та фіксація коміту злиття (Merge Commit).
- Аналіз історії комітів за допомогою `git log --graph --oneline --all`.
